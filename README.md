# Ahorro Compartido 2026 - Reto 100 Sobres 👫💰

¡Bienvenido al reto de los 100 sobres diseñado para parejas! Esta aplicación web te permite ahorrar de forma visual y colaborativa hasta alcanzar la meta de **$5,050** para vuestros planes en 2026.

## 🚀 Producción
La aplicación ya está disponible en: [https://ahorro-compartido-2026.vercel.app/](https://ahorro-compartido-2026.vercel.app/)

## ✨ Características Principales
- **Tablero Visual**: Seguimiento intuitivo de los 100 sobres.
- **Sincronización en la Nube**: Integración nativa con Google Drive para que ambos podáis ver el progreso en tiempo real.
- **Privacidad**: Los datos se guardan en el Drive personal de cada usuario.
- **Personalización**: Nombres de la pareja y logo personalizables.
- **Historial Detallado**: Registro de cada aporte al sueño compartido.
- **Métricas**: Estadísticas de eficiencia y progreso.

## 🛠️ Instalación Local
Si deseas correr el proyecto en tu máquina:

1. **Clonar y entrar**:
   ```bash
   git clone <url-del-repositorio>
   cd Ahorro-Compartido-2026
   ```

2. **Instalar dependencias**:
   ```bash
   pnpm install
   ```

3. **Variables de Entorno**:
   Crea un archivo `.env` con tu Client ID de Google:
   ```env
   VITE_GOOGLE_CLIENT_ID=tu-google-client-id
   ```

4. **Lanzar**:
   ```bash
   pnpm dev
   ```
